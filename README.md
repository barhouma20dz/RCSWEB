# 🏆 نادي الرائد الرياضي المتعدد الرياضات — بلدية سعيدة

الموقع الرسمي الاحترافي لنادي الرائد الرياضي المتعدد الرياضات ببلدية سعيدة، ولاية سعيدة، الجزائر — منصة رقمية عالمية المستوى تجمع كل الفروع الرياضية، لوحات الإدارة، الانتساب الإلكتروني، والمتجر الرسمي.

</div>

---

## ✨ الميزات الرئيسية

| القسم | الوصف |
|---|---|
| 🏠 **واجهة رئيسية عالمية** | قسم بطولي (Hero) بصور وفيديوهات النادي، تعريف، إنجازات، معرض صور، أخبار، مباريات، متجر رسمي |
| 🥋 **فروع رياضية متعددة** | صفحة مخصصة لكل فرع (كرة القدم، اليد، السلة، الكرة الطائرة، الملاكمة، الفنون القتالية، السباحة، الجمباز، ألعاب القوى، الشطرنج، تنس الطاولة، الدراجات) مع اللاعبين والمدربين والنتائج |
| 🏛️ **الإدارة العامة (Admin)** | تحكم كامل: الفروع (إظهار/إخفاء)، الحسابات، الأعضاء، المستندات والكتب الرسمية ومحاضر التنصيب، إعدادات الموقع، صورة الخلفية، معلومات التواصل، سجل الأحداث الأمنية |
| 🏢 **مكاتب الفروع (Office)** | حساب مستقل لكل فرع لإدارة لاعبيه، أخباره، مبارياته، طلبات الانتساب الواردة |
| 📝 **استمارة انتساب ذكية** | تحقق عمري تلقائي: من هم أقل من 18 سنة يُطلب قسم ولي الأمر تلقائياً، ومن 18+ بيانات شخصية مستقلة — مع تحقق مزدوج (واجهة + خادم) |
| 🌙 / ☀️ **الوضع الليلي والنهاري** | تبديل فوري مع حفظ التفضيل |
| 🌍 **ثلاث لغات** | العربية، الفرنسية، الإنجليزية |
| 📱 **PWA** | قابل للتثبيت على الهاتف ويعمل كتطبيق مستقل |
| 🔐 **أمان متقدم** | كلمات مرور scrypt بملح عشوائي، جلسات موقّعة HMAC-SHA256، تحديد معدل الطلبات، سجل أحداث أمنية، إبطال فوري للجلسات عند تغيير كلمة المرور |

## 🛠️ التقنيات المستخدمة

- **Next.js 16** (App Router) + **TypeScript 5**
- **Tailwind CSS 4** + **shadcn/ui** (New York) + Lucide Icons
- **Prisma ORM** + **SQLite**
- **Bun** runtime

## 🚀 التشغيل محلياً

```bash
# 1) تثبيت الحزم
bun install

# 2) إعداد متغيرات البيئة
cp .env.example .env
#   ثم ولّد مفتاحاً سرياً وضعه في AUTH_SECRET:
#   openssl rand -hex 32

# 3) إنشاء قاعدة البيانات وتعبئتها بالبيانات الافتراضية
bunx prisma db push
bun run scripts/seed.ts

# 4) تشغيل خادم التطوير
bun run dev
```

### 🔑 حسابات الدخول الافتراضية

> ⚠️ **تحذير أمني مهم:** هذه بيانات أولية لأغراض التهيئة فقط — **غيّرها فوراً** من لوحة الإدارة بعد أول دخول، ولا تنشر موقعاً حقيقياً بها.

| الحساب | اسم المستخدم | كلمة المرور الافتراضية |
|---|---|---|
| الإدارة العامة | `admin` | `admin123` |
| مكاتب الفروع | مُعرّف الفرع (مثل `football`) | `123456` |

## 📁 بنية المشروع

```
├── prisma/              # مخطط قاعدة البيانات
├── db/                  # ملف SQLite (غير مرفوع إلى git)
├── public/              # الشعار، الصور، الفيديوهات، manifest
├── src/
│   ├── app/             # الصفحات وواجهات API
│   │   └── api/
│   │       ├── admin/   # واجهات الإدارة العامة (محمية)
│   │       ├── office/  # واجهات مكاتب الفروع (محمية + عزل حسب الفرع)
│   │       ├── public/  # واجهات عامة (الرئيسية، الانتساب، المتجر…)
│   │       └── auth/    # تسجيل الدخول/الخروج/الجلسة
│   ├── components/club/ # مكوّنات النادي (الأقسام + لوحات الإدارة)
│   └── lib/             # المصادقة، قاعدة البيانات، أدوات مشتركة
└── docs/                # وثائق المشروع والأمان
```

## 🔒 ميزات الحماية

- **كلمات المرور**: تجزئة `scrypt` بملح عشوائي 16 بايت ومقارنة زمنية ثابتة
- **الجلسات**: توكن موقّع `HMAC-SHA256` بمفتاح سري من البيئة (فشل آمن عند غيابه)
- **عزل الصلاحيات**: كل مكتب فرع يرى بيانات فرعه فقط على مستوى الخادم
- **تحديد المعدل**: حماية نقاط الدخول العامة من الإساءة
- **السجل الأمني**: توثيق محاولات الدخول والتغييرات الحساسة
- **إبطال الجلسات**: تغيير كلمة المرور يُبطل فوراً كل الجلسات السابقة
